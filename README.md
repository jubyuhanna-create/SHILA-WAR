# حرب الشلة 🔫

لعبة طخ أونلاين للتلفون والكمبيوتر. لحد 20 لاعب بكل غرفة، وفيها بوتات لما يكون في لاعبين قلال، وجيمات كل واحد 3 دقايق، ولوحة نتائج بعد كل جيم، وترتيب عالمي.

## شو في جوا

```
server/   سيرفر Node.js بيدير كل اللعبة (الحركة، الرصاص، الإصابات، الهدايا، الجيمات)
client/   صفحة اللعبة، السيرفر نفسو بيعرضها
render.yaml   إعدادات النشر على Render
supabase.sql  جدول الترتيب العالمي (اختياري)
```

## تجربة على الكمبيوتر

```
cd server
npm install
cd ..
node server/index.js
```

افتح http://localhost:3000

## النشر ببلاش على Render

1. ارفع هالمجلد على GitHub كـ repo جديد.
2. ادخل render.com وسجل بحساب GitHub.
3. كبس **New** ثم **Blueprint** واختار الـ repo. Render رح يقرا `render.yaml` لحالو.
4. كبس **Apply** واستنى كم دقيقة.
5. رح ياخد رابط زي `https://shilla-war.onrender.com`، وهاد رابط اللعبة. ابعتو لأي حدا.

ملاحظة: الخطة المجانية بتنام بعد 15 دقيقة بدون لاعبين، وأول واحد بيدخل بعدها بيستنى حوالي دقيقة.

## ترتيب عالمي دايم مع Supabase (اختياري)

بدون Supabase الترتيب العالمي بينمسح كل ما السيرفر ينام. عشان يضل محفوظ:

1. اعمل مشروع جديد ببلاش على supabase.com.
2. افتح **SQL Editor**، الصق محتوى `supabase.sql` وكبس **Run**.
3. من **Project Settings > API** خد الـ Project URL والـ secret key (أو service_role).
4. بـ Render افتح السيرفس، **Environment**، وضيف:
   - `SUPABASE_URL` = الـ Project URL
   - `SUPABASE_SERVICE_KEY` = الـ secret key
5. Render رح يعمل restart لحالو.

لا تحط الـ secret key بالكود ولا على GitHub، بس بـ Render.

## إعدادات

| متغير | الاستعمال |
|---|---|
| `PORT` | Render بيحطو لحالو |
| `MATCH_SECONDS` | طول الجيم بالثواني، الافتراضي 180 |
| `SUPABASE_URL`, `SUPABASE_SERVICE_KEY` | للترتيب العالمي الدايم |

باقي الأرقام (السرعة، الصحة، عدد اللاعبين، البوتات) موجودة بـ `server/world.js`.

## التحكم

- تلفون: الإصبع الشمال بيحرك، واليمين بيوجّه وبيطخ. زر 💣 بيطلع لما يكون معك قنبلة.
- كمبيوتر: WASD للحركة، الماوس للتوجيه والطخ، E للقنبلة.
